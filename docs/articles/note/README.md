# Note Articles

Note 向けの記事管理用 Markdown 置き場です。公開済み記事の元原稿、記事メモ、構成案、下書きを含みます。

## Intended Style

- 背景、問題意識、体験、考え方をやや厚めに書く
- 技術の話は入れてもよいが、主役は読み物としての流れに置く
- 読者が自分事として読める切り口を意識する

## Writing Lens

- まず「なぜそれを作りたくなったか」「何が少し不便だったか」から入る
- `ABC` や譜面データを扱うときの手触りや違和感を主役にする
- 技術詳細は必要最小限にとどめ、判断の背景や実感を厚めに書く
- `Qiita` 側で実装説明をする前提で、`Note` 側は読み物として流れを保つ

## Suggested Themes

- 生成AI と譜面をやり取りするときに `ABC` がちょうどよかった話
- `miku-abc-player` を作るきっかけになった小さな不便
- 譜面を「まず見て鳴らす」までを軽くしたかった話
- `mikuscore` をそのまま使うのではなく、細い派生アプリにした理由

## Reader Angles

- 非エンジニア寄りだが、AI やツールで何か作ってみたい人
- 譜面や音楽データをもっと軽く扱いたい人
- 個人開発や業務改善をしている人
- 自分で全部を書かなくても、音楽データの試行錯誤を進めたい人

## Files

- `TEMPLATE.md`
  - Note 記事テンプレートです。背景や体験を主役にした構成を含みます
