# Qiita Articles

Qiita 向けの記事管理用 Markdown 置き場です。公開済み記事の元原稿、記事メモ、構成案、下書きを含みます。

## Intended Style

- 技術的な背景や実装の話を中心にする
- 読者は開発者や技術に関心のある人を想定する
- 1 記事 1 テーマを意識する
- プロダクト紹介と開発体験は分ける

## Writing Lens

- まず「何を作ったか」「どういう入力と出力を持つか」を明確にする
- `ABC` 中心のプレビュー / 再生アプリとして、どこを意図的に絞ったかを書く
- `mikuscore` との差分は、実装や設計判断として説明する
- 体験談は補助材料にとどめ、本文の主役は仕組みと価値に置く

## Suggested Themes

- `miku-abc-player` の紹介
- `ABC` を会話やブラウザで扱いやすくする意義
- `ABC` 中心のプレビュー / 再生アプリとして何を絞ったか
- `mikuscore` 由来機能をどう細く再利用したか
- URL クエリ入力や軽量な確認フローの話

## Files

- `TEMPLATE.md`
  - Qiita 記事テンプレートです。`想定読者` 欄を含みます
- `20260412-miku-abc-player-intro.md`
  - `miku-abc-player` の最初の紹介記事メモです。まずは素朴な使い方紹介に絞ります
